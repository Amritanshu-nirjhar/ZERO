## The pitch
*4 years. In debt. And still no job?* The hero is a 3D desk scene. The note crumples, and ZERO answers with a path:

- **Careers:** choose a track such as Software Engineering, AI Applied Engineering, Backend, Full Stack, Frontend, or AI & Data Science.
- **Projects:** real briefs, like building an AI rewrite prototype in Gmail, diagnosing why ChatGPT users don't upgrade, or forecasting sales for a sneaker launch.
- **Matching:** the projects you ship become the proof that matches you to roles.
- **Pricing and beta:** from project shipped to interview booked to offer received.

## Built with
Next.js · React · TypeScript · Three.js · Framer Motion · Lenis, plus a custom cursor, magnetic buttons, a velocity text band and optional sound.

## Run it locally
```bash
npm install
npm run dev    # http://localhost:3000
```
